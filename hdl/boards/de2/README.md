# Altera DE2 placeholder

This directory is reserved for the DE2 wrapper and Quartus collateral for the observed Cyclone II `EP2C35F672C6N` FPGA target.

Use Quartus II `13.0sp1` on Windows or Linux for synthesis/programming. Keep macOS as the simulator host unless a VM or separate host provides the legacy Quartus toolchain.

The first board smoke interface should map switches or keys to a small input value and show CRC/status output on LEDs or seven-segment displays.
